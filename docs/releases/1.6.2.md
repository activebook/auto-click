# AutoClick 1.6.2

## Improvements

- **Stop retracts the panel.** Pressing Stop on the floating panel now folds the window back to the
  hand, exactly like Start does. Stop means "I'm done", so the panel no longer lingers over the app.
- **Hide the floating hand entirely.** A new `Hide hand` row in the panel's settings page (and a
  `Hide hand` notification action) puts the hand away and stops the run — no silent background
  tapping you can't see or stop.
- **Bring it back from the settings page.** A new always-visible `Show floating hand` switch in the
  app turns the hand back on. It is disabled until "Display over other apps" is granted. Starting a
  run also re-shows the hand automatically, so a live run always has a visible hand to stop it.

## Install

Download `AutoClick-1.6.2.apk` below and sideload it. Accessibility ("AutoClick taps") and
"Display over other apps" must be enabled; the app walks you through both.
