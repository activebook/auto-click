# AutoClick 1.4.1

**The tap-location ring now shows the truth.**

### What's fixed in 1.4.1

- **"The accessibility service disconnected" no longer sticks.** The system can unbind and rebind
  the service (a reinstall, a permission toggle, a ROM that restarts it). The app treated the
  first unbind as a permanent error and never cleared it, so the banner stayed on screen — with
  no *Enable* button, because the permission really was on — until the process was killed. The
  error is now cleared the moment the service attaches again, and a half-gone service instance
  can no longer withdraw the sink a newer one has already published.

- **The ring no longer lies.** With `Pick exact spot`, the fading crosshair used to be placed at the
  centre of the *selected cell* instead of at the spot you picked, because it was positioned from
  the cell index rather than from the target. Every status update of a running session moved it
  back. The tap itself was already going to the picked pixel; what you saw was not. The marker is
  now resolved from the same target the engine taps from, so it sits exactly where the tap lands.
- **A regression test pins the arithmetic.** A pick at `(884, 2082)` on a 1080 × 2408 screen stores
  as `82% · 86%`, and resolving it again must give `(884, 2082)` back within half a pixel. If a
  future change breaks the round trip, the build fails before it can ship.

Nothing else changed: same permissions, same settings, same behaviour on a fresh install.

### Install

1. Download `AutoClick-1.4.1.apk` below.
2. Open it, allow the install, then open **AutoClick**.
3. Turn on **AutoClick taps** in Accessibility and **Display over other apps** — the app's two
   buttons take you straight to each screen.
