**Tap one cell of a 3×3 screen grid every N seconds — with a floating hand that stays on top of every app.**

### What's in 1.2.0

- **Nine-grid targeting** — pick a cell (or aim at the real screen with the full-screen picker); the tap lands in the exact centre of that third.
- **Floating hand** — 56 dp, translucent, draggable, snaps to the edge, and prints `ON` / `OFF` / `PAUSED` under the glyph.
- **Controls without leaving the app** — Start/Stop, an in-panel settings page (target cell + `−/+` interval), Minimize, and `Open` to bring the full app forward. A successful start folds the panel away after 160 ms.
- **Seconds, not guesswork** — 1 s to 3600 s, default 1 s, presets 1/2/5/10/30/60.
- **Honest hand-off** — `Enable Accessibility` opens the accessibility list scrolled to the `AutoClick taps` row, while two system Toasts explain the wait: *Finding "AutoClick taps" — please wait* → *Click the highlighted row*.
- **Never swallows its own tap** — refuses to start when the hand covers the target, and skips (and counts) a tick if the hand is dragged over it mid-run.
- **Drift-free timing** — anchored schedule, no burst after a freeze, Stop is final.
- **Settings that survive a restart** — the switches keep what you chose; only the two required permissions gate `Start tapping`.

### Install

1. Download `AutoClick-1.2.0.apk` below.
2. Open it with a file manager; allow "Install unknown apps" when asked.
3. Android 13+: **Settings → Apps → AutoClick → ⋮ → Allow restricted settings** before the accessibility toggle can be turned on.
4. Grant **Accessibility ("AutoClick taps")** and **Display over other apps** — `Start tapping` stays disabled until both are on.
