# AutoClick 1.5.0

## New

- **Custom tap budget.** "Stop after" now offers the presets **Never · 1 · 3 · 5 · 10 · 100**
  and a numeric field with an **Apply** button, so any budget from 0 to 100 000 can be typed in
  (0 = never). It works exactly like the interval field: digits only, out-of-range values turn
  the field red and disable Apply, and the live summary line confirms what will happen.

## Under the hood

- Follows the 1.4.1 repository cleanup: dead geometry helpers and the debug tracer removed,
  deprecated Material `Divider` replaced, and two latent overlay/handler bugs fixed.

## Install

Download `AutoClick-1.5.0.apk` below and sideload it. Accessibility ("AutoClick taps") and
"Display over other apps" must be enabled; the app walks you through both.
