# AutoClick 1.6.5

## Improvements

- **Consistent with the app.** The floating hand and the control panel now use the app's own
  white/green theme (white surface, teal-green accent, mint-tinted secondary buttons) instead of
  the dark glass introduced in 1.6.4. They follow light/dark mode just like the rest of AutoClick.
- **A right-sized hand.** The floating hand is now 40 dp (was 44 dp): a compact controller that
  still keeps a large 28 dp hand glyph with the tiny ON/OFF word tucked close beneath it (a ~2 dp
  hairline, never overlapping). The countdown ring scales to match.
- The long-press hide popup stays dark on purpose: it is the single "put it away" affordance and
  reads as distinct from the white/green controls.
- **Hugs the edge.** The hand now snaps to within 4 dp of the screen edge (was 12 dp) and uses the
  full display width, so curved-edge / side gesture-bar insets no longer add dead space.

Everything else behaves exactly as in 1.6.3/1.6.4: tap = panel, drag = move, long-press = hide
popup, Stop retracts the panel, and the settings page brings a hidden hand back.

## Install

Download `AutoClick-1.6.5.apk` below and sideload it. Accessibility ("AutoClick taps") and
"Display over other apps" must be enabled; the app walks you through both.
