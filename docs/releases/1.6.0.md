# AutoClick 1.6.0

## New

- **Countdown ring on the floating hand.** While a run is live, a circular progress ring sweeps
  clockwise around the hand, filling over exactly one interval. The moment it completes, the tap
  lands and the ring snaps back to empty and starts again — a visible countdown for every cycle,
  repeating until you stop or the tap budget is reached.
  - The ring is driven by the engine's own delivered-tap signal, so it stays in step with the real
    taps rather than running on a separate, drifting timer.
  - It hides when idle, paused or finished, so the hand looks unchanged outside a live run.
  - Changing the interval mid-run re-times the ring immediately; it is independent of the
    "Flash marker" feedback toggle.

## Install

Download `AutoClick-1.6.0.apk` below and sideload it. Accessibility ("AutoClick taps") and
"Display over other apps" must be enabled; the app walks you through both.
