**Tap the middle of a cell, or the exact pixel you point at.**

### What's in 1.4.0

- **Exact spot** — the target card now has two entries, `Pick a cell` and `Pick exact spot`. Each
  opens the full-screen picker already in that mode, so the screen you aim at carries nothing but
  one line of instructions. `Pick exact spot` turns the thirds into faint guides and commits the
  point you touch: the tap lands there, down to the pixel, instead of in the middle of a cell.
- **Stored as a fraction, not a pixel** — the point is a position *relative to the usable screen*,
  so rotating the phone, changing resolution or growing the status bar moves the target with the
  screen instead of leaving it off-screen. An older install with no such setting keeps the cell
  behaviour, unchanged.
- **The app tells you which mode is live** — the filled of the two buttons *is* the live mode, the
  target card shows a pin at the spot and reads `Exact spot · 65% · 34%`, the panel's grid shows the
  same pin, and `Pick a cell` goes back to coarse aiming. Nothing looks like a selected cell when
  the target is not one.
- Everything from 1.3.0: tap budget with a green **DONE**, the floating hand, in-panel controls,
  full-screen cell picking, drift-free timing, pause on screen off, and the trimmed interface.

### A note on what "exact" means

The point is a **fixed screen coordinate**. It does not follow a page as it scrolls, and it does not
become "the button with that label" — so if the app underneath moves its content, the same pixel is
a different control. That is inherent to coordinate tapping, not a defect, and the picker says it in
one line rather than hiding it.
