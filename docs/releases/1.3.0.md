**Tap one cell of a 3×3 screen grid every N seconds — now with an ending you can set.**

### What's in 1.3.0

- **Tap budget** — `Stop after`: `Never` (default), 100, 500 or 1000 taps. The loop ends by itself
  on the tap that reaches the number; skipped or cancelled ticks do not count against it.
- **A finished run says so** — the hand turns green and reads **DONE**, the state word on the app
  page reads `Finished`, the notification reads `Finished its tap budget · 500 taps delivered`, and
  Start begins a fresh session. Before this, a completed run was indistinguishable from never
  having started.
- **Lowering the budget mid-run** ends the session immediately instead of spending one more tap you
  just said you did not want.
- **Less text, same information** — the permanent status sentences on the app page, in the panel and
  under the interval stepper are gone: the state dot, the play/stop glyph and the grid already said
  it. A sentence now appears only to explain a failure. The panel's third button is a close **X**.
- Everything from 1.2.0: nine-grid targeting with the full-screen picker, the floating hand with
  `ON / OFF / PAUSED / DONE`, in-panel controls, drift-free timing, pause on screen off.

### Install

1. Download `AutoClick-1.3.0.apk` below.
2. Open it with a file manager; allow "Install unknown apps" when asked.
3. Android 13+: **Settings → Apps → AutoClick → ⋮ → Allow restricted settings** before the
   accessibility toggle can be turned on.
4. Grant **Accessibility ("AutoClick taps")** and **Display over other apps** — `Start tapping` stays
   disabled until both are on.
